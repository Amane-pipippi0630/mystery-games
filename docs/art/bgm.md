# BGM・環境音・効果音

場面の空気は**環境音**で出し、BGM はその上に流す。BGM は OpenTracks（旧DOVA-SYNDROME）の15曲、環境音と効果音はプログラムで作った。曲名・作曲者・ライセンスは [audio/CREDITS.md](../../audio/CREDITS.md)、書き方は [engine/README.md](../../engine/README.md) の「音」。

## 決めたこと（2026-11-25）

- 最初は Suno で作る予定だったが、無料プランではダウンロードできず商用利用もできないため、OpenTracks の素材にした
- BGM は15曲：全作品で共通の「事件」「推理」2曲と、作品ごとの「捜査」「対峙」「エンディング」
- 作品選択の画面には曲を流さない（タップするとすぐ作品のページに移るので、流しても聞こえない）

## 音の重ね方

| 場面 | BGM | 環境音 |
|---|---|---|
| 捜査（調べる・聞く・移動） | 作品の「捜査」を少し小さめに | その場所の音 |
| 事件発生 | 共通の「事件」 | その場所の音を残す |
| 推理（推理・選択式の問い・番号の謎・記事の検索・推理ボード・矛盾をつく） | 共通の「推理」 | 止める |
| 対峙 | 章のはじめに**すべての音を一度止め**、間をおいて作品の「対峙」 | その場所の音 |
| エンディング | 作品の「エンディング」 | 止める |

## 効果音

| 名前 | 鳴るとき |
|---|---|
| `se_step_wood`・`se_step_gravel`・`se_step_asphalt` | 移動（鴎島は館の床、冬の汐見は砂利、ほかはアスファルト） |
| `se_select` | ボタンを押したとき（「つぎへ」は鳴らさない） |
| `se_note` | 証言カード・取材ノート・もちもの・資料が増えたとき |

## 音のファイル

- 形式は m4a（AAC）。BGM は 96kbps、環境音は 80kbps。合計約33MB
- BGM は頭と終わりの無音を切り、ループする曲は終わり3秒を頭に重ねて切れ目なく回るようにした。音量は -18 LUFS にそろえた
- 環境音は32秒で切れ目なくループする
- 音は鳴らすときに読み込む（背景画像のように起動時にまとめて読まない）。読み込めなくても遊べる
