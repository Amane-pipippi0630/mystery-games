## 1. 前史（1941〜1958）

### 1941年（昭和16）秋　汐見・磯辺町の火事
- 網元・戸川家の網倉が燃え、戸川家の長男が死ぬ。
- 疑われたのは、貧しい漁師の息子・**佐伯 修**（19歳）。網倉に出入りしていたから、というだけの理由だった。
- 本当の火元は、戸川家の次男・**戸川 源次**（19歳）の煙草の不始末。源次は黙り通す。
- 佐伯は逃げるように志願して入隊する。若い巡査だった**沖田 庄吉**は、佐伯がやったとは思えず、心に引っかかったまま事件は終わる。

### 1944〜1946年　南方の戦地と引き揚げ船
- 佐伯は南方の部隊で、東京出身の**久我 誠一郎**と出会う。背格好が似ていて、同い年。久我は大学出で、佐伯に読み書きや帳簿を教える。
- 1946年6月、浦賀へ向かう引き揚げ船の中で、久我は発疹チフスで倒れる。
- 死ぬ前に久我は言う。「おまえは故郷に帰れば放火犯だ。おれには、目の見えない母しかいない。おれの名前で生きてくれ。母を頼む」
- 佐伯は久我の認識票と書類を受け取る。船の記録では「佐伯修」が死亡・水葬とされる。
- 同じ船に、汐見出身の戸川源次も乗っていた。源次は入れ替わりに薄々気づくが、そのときは何も言わない。
- 佐伯はこの日から、手帳を書きはじめる（**鳶色の手帳**）。最初のページは、久我との約束。

### 1946〜1958年　「久我誠一郎」の成功
- 佐伯は久我として、信州の寺に身を寄せていた久我の母・**志乃**を訪ねる。志乃は目が見えない。佐伯は息子として振る舞い、毎月の仕送りと見舞いを、志乃が亡くなる1956年まで続ける。
- 1950年、闇市の商売から「久我海運」を興す。帳簿と人を見る目で会社は急成長する。片腕は専務の**黒田 惣一郎**。
- 1954年に**美代子**と結婚し、1955年に娘の**千鶴**が生まれる。
- 志乃は亡くなる前、寺の住職に1通の手紙を口述し、「誠一郎に」と託す。佐伯はそれを手帳の最後のページに貼る（中身は隠しエピローグで明かす）。

## 2. ③ 清張リスペクト作『冬の汐見』（仮）― 1959〜1960

**主人公**：沖田 庄吉（48歳、汐見署の部長刑事）
**相棒**：早瀬（警視庁捜査一課の若手刑事）、三島 透（汐見日報の記者、24歳）
**犯人**：久我誠一郎＝佐伯修
**苦さ**：段階3（佐伯は冬の海に消え、真相は世に出ない）

### 事件の真相
- 1958年秋、落ちぶれた戸川源次は、新聞に載った久我海運の新社屋の写真で、社長が佐伯だと気づく。
- 源次は佐伯をゆすり始める。要求はふくらみ、「汐見の警察に、佐伯は生きていると言う」と脅す。そうなれば、妻の美代子と千鶴の暮らしも、久我の母との約束もすべて壊れる。
- 1959年2月10日の夜、佐伯は品川の安宿で源次を絞め殺す。

### トリック（時刻表アリバイ）
- 佐伯の主張：「2月10日の夜は、東京発の夜行急行で大阪へ向かっていた」。寝台券の半券があり、車掌の検札記録にも「久我」の名がある。
- 実際：夜行に乗ったのは、書類を届けるよう頼まれた部下。検札は切符を見るだけで、顔は見ない。
- 佐伯は殺害後、翌朝の特急で大阪へ向かい、昼すぎにホテルで「朝から休んでいた」ふりをする。
- **死亡推定時刻のずれ**：真冬の暖房のない部屋で、窓を少し開けておいた。遺体が冷え、推定時刻が「11日の昼〜夜」と遅くずれる。さらに11日の朝、源次の外套と帽子を身につけた佐伯が宿の主人の前を通り、「あと2晩泊まる」と言って代金を払っている。
- プレイヤーは時刻表を見ながら「品川で11日の朝7時に目撃される → 東京駅9時発の特急 → 大阪着」のルートを組み立て、アリバイを崩す。

### 章立て
1. **冬の品川**（1959年2月）
   身元不明の男の絞殺体が見つかる。所持品は、汐見行きの切符の半券と、写真の部分だけ破り取られた新聞の切り抜き。警視庁から汐見署へ身元の照会が来る。
2. **汐見の海**
   沖田は遺体が戸川源次だと突き止める。源次は「金づるを見つけた」と飲み屋で自慢していた。沖田は18年前の網倉の火事と、戦死したはずの佐伯修を思い出す。汐見日報の三島透と知り合う。
3. **東京へ**
   沖田は上京し、早瀬と組む。源次の東京での足取りをたどると、金貸しへの借金と、久我海運への何度もの訪問が見えてくる。
4. **久我誠一郎**
   久我社長は穏やかで隙がない。夜行急行のアリバイもある。ただ一度だけ、汐見の漁師言葉がこぼれるのを、沖田は聞き逃さない。
5. **時刻表**
   検札の記録、部下の出張、ホテルの記帳を一つずつ洗う。死亡推定時刻の矛盾に気づき、時刻表の上で「空いている時間」を見つける。（時刻表アリバイ崩しの山場）
6. **名前の行方**
   三島が引き揚げ船の記録と戦友の証言を集める。「佐伯修 水葬」の記録と、背格好の似た二人の兵隊の話。信州の寺で、沖田は生前の志乃を知る住職に会う。「誠一郎さんは毎月欠かさず来られました。母上は、それはうれしそうで」
7. **焼けた網倉**
   汐見に戻った沖田は、1941年の火事の元が源次の煙草だったことを証明する。佐伯は放火犯ではなかった。それでも、源次を殺したのは佐伯だ。
8. **冬の海**（結末・苦さ3）
   佐伯は18年ぶりに汐見に戻り、両親の墓に参っている。夜明けの浜で、沖田と二人きりで向き合う。佐伯はすべてを認める。「全部、手帳に書いた。東京の書斎にある。娘が大人になったら、読ませてやってほしい」。そして三島に1通の封筒を渡すよう沖田に頼み、沖田が目を離したすきに冬の海へ歩いていく。遺体は上がらない。
   - 沖田は東京の書斎へ急ぐが、専務の黒田が先に手帳を持ち去っていた。黒田は「そんなものはない」と言い張る。
   - 上からの圧力で、品川の事件は「犯人不明」のまま捜査が打ち切られる。新聞は「久我海運社長、冬の海で事故死」とだけ書く。三島は記事を書くことを禁じられる。
   - 沖田は三島に言う。「いつか手帳が見つかったら、あの子に届けてくれ」
   - 最後に残る問い：「名前を奪った男は、本物の持ち主を殺したのか、それとも託されたのか」。答えは手帳の中にあるが、誰も読めない。

## 3. 空白の60年（1960〜2025）

- **黒田家**：黒田惣一郎が会社を継ぎ、創業者の名前を残して「久我グループ」とする。手帳が世に出れば、創業者が他人の名を騙っていたことになり、会社の成り立ちそのものが揺らぐ。黒田は手帳を汐見沖の孤島・**鴎島**の別邸「久我館」の書庫にある隠し金庫にしまい、誰にも見せない。
- **美代子と千鶴**：夫の戸籍が偽りだったため、結婚そのものが無効になる。美代子は旧姓の宮下に戻り、千鶴を連れて東京の下町へ移る。千鶴には「父は事故で死んだ」とだけ伝える。
- **千鶴**：大人になって、父が「名を騙った男」と噂されていたこと、品川の事件の噂を知る。父は人殺しだったのか。それを知るため、生涯をかけて手帳を探す。時計職人になり、墨田区で「宮下時計店」を営む。
- **磯村**：1960年、18歳の書生として久我家にいた。佐伯が冬の海に消えた1960年12月、黒田に命じられて書斎の手帳を預かり、1962年に久我館が建つと、書庫の隠し金庫に入れた。その後、黒田家の執事として50年以上仕えながら、ずっとそのことを悔いている。
- **三島透**：沖田との約束を胸に、手帳と千鶴を探し続けるが見つけられない。2015年に亡くなり、取材メモと佐伯の封筒は孫の**三島陽**に残る。
- **沖田**：1975年に退職し、1998年に亡くなる。汐見署には、沖田の古い表彰写真が今も飾られている。
- **2025年11月**：汐見署の警部とマコトが、汐見水産の社長殺しを解決する（汐見港殺人事件。本筋とは関係ない）。

## 4. ② 有栖川リスペクト作『鴎島館の論理』（仮）― 2026年8月

**語り手**：葛西 湊（かさい みなと、32歳、大阪在住の本格ミステリ作家。大阪弁）
**探偵役**：鷹宮 恭介（たかみや きょうすけ、34歳、京都の大学の論理学講師。葛西の大学ミステリ研の先輩）
**犯人**：黒田 圭（35歳、康彦の息子、久我グループ専務）

### 登場人物
| 人物 | 年齢 | 立場 |
|---|---|---|
| 黒田 タキ | 88 | 当主。惣一郎の未亡人。米寿を迎える |
| 黒田 康彦 | 62 | 長男。久我グループ社長 |
| 黒田 玲子 | 58 | 長女。ホテル部門の責任者 |
| 黒田 圭 | 35 | 康彦の息子。専務。来月に大型合併を控える |
| 黒田 沙耶 | 28 | 玲子の娘。建築家。館の改修を任されている |
| 磯村 | 84 | 執事。黒田家に66年仕える |
| 浅見 理沙 | 40 | 顧問弁護士 |
| 三島 陽 | 38 | フリー記者。グループの社史の取材で招かれた |
| 葛西 湊・鷹宮 恭介 | 32・34 | タキに「創業者の伝記小説」を依頼された作家と、その手伝い |

### 事件の真相
- タキは惣一郎から、創業者の秘密をうすうす聞かされていた。米寿の祝いで「グループの一族支配をやめ、財産の大半を汐見の町の財団に寄付する」と発表するつもりで、弁護士の浅見に新しい遺言書を作らせていた。
- それを知った圭は、合併と自分の地位を守るため、発表の前に遺言書を消そうとする。

### 殺人とトリック
- **第1の殺人（書庫の密室）**：嵐の夜の停電中、圭は西棟の廊下で浅見を刺す。浅見は書庫に逃げ込み、内側から閂をかける。犯人から遺言書を守るため、知っていた書庫の隠し金庫に遺言書を押し込み、そこで息絶える。
  → 密室は犯人が作ったのではなく、被害者が作った。そして金庫が開いていたことで、60年眠っていた手帳が見つかる。
- **第2の殺人（崖の灯台）**：父の康彦は、宴のあと圭から遺言のことで内線があったことから圭を疑い、灯台で問いただそうとする。圭は嵐の灯台の崖で康彦を突き落とし、事故に見せかける。
- **犯人を絞る条件（消去法推理ボード）**：
  1. 停電中の20分間に、西棟にいることができた
  2. 浅見が新しい遺言書を持っていることを知っていた（タキの宣言を大食堂で聞いた）
  3. 隠し金庫の存在を知らなかった（知っていれば、第1日の午前に無人の書庫から遺言書を取り出せたはず。浅見の客室を荒らしたのも、金庫を知らなかったから）
  4. 第2の殺人の時刻（第2夜22:00〜22:20）にアリバイがない（濡れた雨具1着、通用口の鍵は無人の執事室の鍵棚）
  → 4つすべてを満たすのは圭だけ。詳しくは [games/kamomejima/WALKTHROUGH.md](../games/kamomejima/WALKTHROUGH.md)
- **動機を全員に配る**：合併は康彦と圭の二人の案件。玲子はホテル計画、沙耶は事務所の資金繰り、三島は書庫の資料、磯村は手帳の秘密を抱えている。圭だけを目立たせない（設計書の3.5）。
- **目くらまし**：三島陽と磯村は、二人とも夜中に書庫のまわりをうろついている。二人が探していたのは遺言書ではなく手帳。鷹宮は「手帳を探す者」と「遺言書を消したい者」を分けて考え、二つの謎を切り離す。

### 章立て
1. **鴎島へ**：葛西と鷹宮が連絡船で鴎島へ。一族、執事、弁護士、記者がそろう。タキは「明日、大事な発表がある」と告げる。夜、嵐が来る。
2. **書庫の密室**：翌朝、閂のかかった書庫で浅見が死んでいる。連絡船は止まり、電話もつながらない。島は孤立する。
3. **鷹宮の講義**：現場検証と密室講義。三島と磯村の怪しい動き。一族の誰もが遺言の中身を知りたがっている。
4. **隠し金庫**：開いていた隠し金庫から、新しい遺言書と、古い鳶色の手帳が見つかる。葛西は手帳の最初のページを読む（「久我と約束した。おれは今日から久我誠一郎になる」）。三島は、祖父の取材メモのことを打ち明ける。
5. **崖の灯台**：康彦が崖下で見つかる。事故か、殺人か。
6. **二つの謎**：手帳を探す者と、遺言書を消したい者を分けて考える。一人ずつ容疑者を外していく。
7. **読者への挑戦**：「犯人を特定する材料は、すべて出そろった」。セーブを促す。
8. **解決**：消去法で圭を指名し、圭は崩れる。嵐が去り、警察の船が着く。タキは遺言どおりの発表をする。
   - 最後の場面：鷹宮が客室の鞄にしまっていた手帳が消えている。代わりに磯村の筆跡のメモが残っている。「長いあいだ、預かりものをしておりました。持ち主のお嬢さまにお返ししてまいります」

## 5. ① 東野リスペクト作『振り子の止まる夜』（仮）― 2027年1月

**探偵役**：桐生 直也（36歳、警視庁捜査一課の刑事）と、白石 澪（39歳、大学の物理学准教授。桐生の大学時代の同期）
**犯人**：宮下 千鶴（71歳、時計職人）と、孫の宮下 蒼（19歳、工業大学の学生）
**構成**：倒叙（第1・2章は犯人側の視点）

### 事件の真相
- 2026年12月、執事を辞めた磯村が「宮下時計店」を訪ね、千鶴に手帳を返す。手帳には最後のページがない（破り取った跡がある）。
- 2027年1月の夕方、久我グループの元総務部長・**長尾 秀樹**（68歳）が店に来る。長年、黒田家の汚れ仕事を引き受けてきた男で、磯村の足取りを追ってきた。長尾は「処分しろと言われている」と手帳を奪い、作業場のストーブに投げ込もうとする。
- もみ合いになり、突き飛ばされた千鶴は、とっさに手にしていた大時計の真鍮の振り子で長尾を打つ。長尾は倒れて動かなくなる。
- 帰ってきた蒼が、それを見る。

### トリック（理系トリック）
- 蒼は祖母を守るため、配達用の台車とワゴン車で、長尾の遺体を隅田川沿いに停めた長尾自身の車まで運ぶ。
- 車のエンジンをかけて暖房を最強にし、遺体の冷え方を遅らせる。死亡推定時刻を「20時ごろ」にずらす。その時間、千鶴は町内会の新年会に出ていて、大勢が証人になる。
- 店の振り子時計のうち1台は、振り子を外したときに止まり、蒼があわてて時刻を合わせ直したため、ほんのわずかに狂っている。
- **白石の検証**：
  1. 燃料の減り方と車の暖房の消費量から、エンジンは3時間近く動いていた
  2. 外は氷点下なのに、フロントガラスの霜の溶け方が「20時に死んだ人を乗せた車」と合わない
  3. 振り子の長さと温度の関係から、1台だけ狂っている時計がいつ止められたかを逆算する
  → 死亡は17時台、場所は時計店だと証明される。

### 章立て
1. **鳶色の手帳**（倒叙・千鶴）：12月、磯村が手帳を返しに来る。千鶴は少しずつ読み進め、父が品川で人を殺したことを知る。1月のある夕方、長尾が来る。もみ合いと、振り子。
2. **夜の隅田川**（倒叙・蒼）：蒼は祖母に「ばあちゃんは新年会に行って」と言い、一人で遺体を運び、暖房を入れる。物理を学ぶ学生として、死亡推定時刻をずらす計算をする。
3. **冷たい車**（桐生）：翌朝、川沿いの車で長尾の遺体が見つかる。死亡推定は20時ごろ。長尾の身元から、黒田家と久我グループが浮かぶ。
4. **物理学者**：桐生は白石を訪ねる。白石は車のメーターと霜の写真を見て、「この車は、3時間ずっと誰かを温めていた」と言う。
5. **時計の街**：長尾の手帳に「宮下時計店」の名前。千鶴は穏やかに応じる。店には30台の時計があり、1台だけが17秒遅れている。（検証パート：振り子と温度）
6. **三島陽**：記者の三島が、手帳の来歴を桐生に語る。1959年の品川の事件、鴎島の事件、磯村。千鶴が誰の娘なのかが分かる。
7. **検証**：燃料、霜、振り子の3つの実験で、死亡は17時台の時計店だと証明する。蒼の大学の実験ノートに、温度と冷却の計算が残っている。
8. **なぜ**：蒼は「全部ぼくがやった」と言う。千鶴は首を振る。
   - プレイヤーは最後に「蒼が遺体を動かしたのはなぜか」を選ぶ。
   - 答え：祖母を捕まらせたくなかったからだけではない。「ばあちゃんは、一生かけて手帳を探してたんだ。せめて最後まで読む時間をあげたかった」
   - 千鶴は、父が自分の暮らしを守るために人を殺したことを、手帳で知ったばかりだった。そして自分も、孫を守ろうとして同じ場所に立っている。
   - 千鶴は過剰防衛として起訴され、執行猶予の判決を受ける。蒼は死体遺棄で保護観察となる。
   - 最後の場面：千鶴は手帳の破り取られた最後のページの跡をなでる。「ここに、何が書いてあったんでしょうね」
