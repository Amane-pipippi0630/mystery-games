## 1. 真相

**1959年2月10日の夜、品川の安宿「千鳥屋」で戸川源次（37）を絞め殺したのは、久我海運社長・久我誠一郎――本当の名は佐伯修（37）。**

| 項目 | 内容 |
|---|---|
| 動機 | 源次は1946年の引き揚げ船で入れ替わりに気づいていた。1958年秋、新聞の写真で社長が佐伯だと知り、ゆすり始める。「汐見の警察に、佐伯は生きていると言う」。そうなれば妻と娘の暮らしも、久我の母との約束も壊れる |
| アリバイ | 「10日の夜は、夜行急行『夜汐』で大阪へ向かっていた」。社長名義の寝台券があり、車掌の検札記録もある |
| 実際 | 夜汐に乗ったのは秘書の野々村。書類を大阪支店へ届ける役で、社長名義の寝台を使わされた。検札は切符を見るだけで、顔は見ない。野々村は11日9時5分、大阪のホテルに「久我誠一郎」と記帳した |
| 偽装① | 殺したあと、窓を3cm開け、火鉢の火を消した。真冬の部屋は0℃近くまで冷え、遺体の傷みが遅れる。発見（13日）の検案は「11日の昼〜夜」 |
| 偽装② | 11日朝7時、源次の外套と帽子で千鳥屋の主人の前を通り、「あと2晩、たのまぁ」と宿代を払う。源次も佐伯も汐見の生まれで、同じ言葉を話す |
| 移動 | 品川7時08分発の電車特急「朝凪」で大阪13時58分着。15時、ホテルのロビーで大阪支店長と会い「朝から部屋で休んでいた」 |
| 結末（苦さ3） | アリバイは崩れるが、上からの圧力で捜査は打ち切られる。1960年12月、佐伯は汐見の浜で沖田にすべてを認め、冬の海へ歩いていく。遺体は上がらない。手帳は黒田が持ち去る |

> **注**：docs/story.md では「遺体が冷えて推定時刻が遅くずれる」となっていたが、冷えると体温からの推定はむしろ早くずれる。この作品では、発見が2日半後で体温はもう室温と同じなので、**腐敗の進み方**で時刻を見立てる。寒さで腐敗が遅れ、死んだのが遅く見える、という形にした。
