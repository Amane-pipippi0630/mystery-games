## 1. 真相（ひとことで）

**犯人は黒田 圭（35歳、専務）。** 祖母タキが「一族の支配をやめ、財産を汐見の財団に寄付する」新しい遺言を発表しようとしていた。来月の大型合併を守るため、圭は発表の前夜、遺言書を預かっていた弁護士の浅見を刺した。翌晩、それに気づいた父の康彦を、灯台の崖から突き落とした。

| 項目 | 内容 |
|---|---|
| 第1の殺人 | 第1夜 22:40〜23:00 の停電中、西棟の廊下で浅見を刺す |
| 書庫の密室 | 犯人ではなく**被害者が作った**。刺された浅見は書庫に逃げ込んで内側から閂をかけ、隠し金庫に遺言書を押し込んで息絶えた |
| 手帳 | 浅見が金庫を開けたまま死んだため、60年眠っていた鳶色の手帳が見つかる（犯人とは関係ない） |
| 第2の殺人 | 第2夜 22:00〜22:20、嵐の灯台の崖で康彦を突き落とす。事故に見せかける |
| 決め手 | 4つの条件を積み上げると、満たすのは圭ひとり（→ 7. 推理ボード） |

## 2. 舞台：鴎島と久我館

汐見港から連絡船で40分の小さな岩の島。館は黒田家の別邸「久我館」（1962年築）。

```
              ［灯台］─ 崖
                 │（外の小道・徒歩5分）
   ┌──────── 西棟 ────────┐      ┌──────── 本館 ────────┐
 2F│ タキの私室 / 浅見の客室  │      │ 客室（一族・客人）      │2F
 1F│ 書庫 / 執事室 / 西棟廊下 │═渡り廊下═│ 玄関ホール / 大食堂 / 談話室 / 厨房 │1F
 B1│ 乾燥室・ボイラー（自家発電）│      └──────────────────────┘
   │ 通用口（外へ。夜は施錠）  │
   └──────────────────────┘
```

- 本館と西棟をつなぐのは1階の**渡り廊下だけ**（ガラス張り、約40m）
- 西棟の**通用口**は外の小道（灯台へ続く）に出られる。毎晩21時に執事の磯村が施錠し、鍵は**執事室の鍵棚**に掛ける
- 書庫の扉は、外から鍵、内側に**閂**。隠し金庫は右の本棚の奥

**背景の対応**（`docs/art/kamomejima-backgrounds.md`）：pier / island / exterior / hall / dining / salon / guestroom / library / library-safe / corridor（西棟廊下）/ drying（乾燥室）/ butler（執事室）/ cliff（灯台の崖）/ terrace（エンディング）

### 第1章 鴎島へ
- **流れ**：汐見港で葛西と鷹宮が三島と乗り合わせる → 島に着き、磯村の案内で館へ → 一族と顔合わせ → 米寿の宴 → 嵐 → 停電で章が終わる
- **できること**：人物全員と顔合わせ（会話が多い章）、館の案内、宴のイベント
- **手がかり**：k01（宴のイベント）、k02（三島が席を立つのを見る）、k04の前ぶれ（沙耶「書庫の壁、図面と寸法が合わないのよ」）、圭と康彦の合併をめぐる口論、磯村が通用口を施錠する場面
- **終わる条件**：全員と一度話し、宴のイベントを見る → 談話室で停電

### 第2章 書庫の密室
- **流れ**：朝、書庫の閂に気づき、扉を壊すと浅見の遺体 → 島の孤立 → 停電中の居場所の聞き込み
- **手がかり**：k05・k07・k09・k10・k12・k13・k14、k02・k03（三島の聞き込み）
- **終わる条件**：全員の停電中の居場所を聞き、書庫と西棟廊下を調べる → 鷹宮「この密室は、犯人が作ったもんやないかもしれん」

### 第3章 鷹宮の講義
- **流れ**：談話室で鷹宮の密室講義 → 「密室は被害者が作った」という仮説 → 浅見の客室が荒らされているのを見つける → 三島のうそを崩す（m2）
- **手がかり**：k08・k15・k16・k18・k19
- **終わる条件**：m2を解き、書庫の本棚の血のあと（k16）を調べる

### 第4章 隠し金庫
- **流れ**：本棚の奥の隠し金庫を見つける → 遺言書と鍵付きの小箱 → 小箱の謎（p1） → 手帳の最初のページを読む → 磯村のうそを崩す（m3） → 三島が祖父のメモを見せる
- **手がかり**：k04（図面を見せてもらう）・k06・k17・k24
- **終わる条件**：p1とm3を解く → 夜、康彦が部屋を出ていく足音で章が終わる

### 第5章 崖の灯台
- **流れ**：早朝、康彦が崖下で見つかる → 事故か殺人か → 濡れた雨具と通用口の鍵
- **手がかり**：k20〜k23
- **終わる条件**：崖・乾燥室・執事室を調べ、第2夜の居場所を全員に聞く

### 第6章 二つの謎
- **流れ**：鷹宮「この館には、謎が二つある。手帳を探す者と、遺言を消したい者や」 → 手帳の謎（三島・磯村）を切り離す → 圭のうそを崩す（m1） → 内線の記録（k25）
- **手がかり**：k11・k25、m1
- **終わる条件**：m1を解く → 推理ボードの条件がすべて出そろう

### 第7章 読者への挑戦
- **流れ**：葛西の語りで「犯人を特定する材料は、すべて出そろった」と宣言 → セーブを促す → 推理ボードで条件①〜④を選んで積み上げ、容疑者を外していく → 最後に残った1人を指名
- **ボード**：条件は8つの候補から正しい4つを選ぶ（まちがった条件を選ぶと、残る人がいなくなる・2人以上残るなどで分かる）
- **終わる条件**：圭を指名

### 第8章 解決
- **流れ**：談話室で鷹宮の解決編（プレイヤーが選んだ条件の順に語る） → 圭が崩れる → 嵐が去り、警察の船 → タキが遺言どおりに発表 → テラスの朝
- **最後の場面**：書庫に置いていた手帳が消えている。磯村のメモ「長いあいだ、預かりものをしておりました。持ち主のお嬢さまにお返ししてまいります」（→ 第二作へ）
