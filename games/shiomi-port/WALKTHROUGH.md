## 4. 最短攻略チャート

逮捕に必要な証拠は4つです。

- **動機**：野村に帳簿を見せて、送金先を明らかにする
- **機会**：薬剤師にカプセルを見せる
- **手段**：大場の鑑定書を受け取る
- **片桐のうそ**：片桐の「薬には関わっていない」を、証言カードで崩す（矛盾をつく）

| # | 場所 | コマンド | 結果 |
|---|---|---|---|
| 1 | 書斎 | しらべる → 薬瓶 | **カプセル**入手 |
| 2 | 書斎 | しらべる → 机 | **机のメモ**入手（任意） |
| 3 | 居間へ移動 | しらべる → 写真立て | 金庫の番号のヒント「沙織 誕生 7月14日」 |
| 4 | 居間 | みせる → カプセル → ハル | 片桐が薬を受け取ったと判明。病院が解放 |
| 5 | 警察署へ移動 | みせる → カプセル → 大場 | 鑑定が始まる（移動を1回するとできあがる） |
| 6 | 書斎へ移動 | しらべる → 金庫 → **0714** | **帳簿のコピー**入手 |
| 7 | 汐見水産へ移動 | みせる → 帳簿のコピー → 野村 | 送金先は片桐の口座 → **動機**。事務所が解放 |
| 8 | 汐見病院へ移動 | みせる → カプセル → 薬剤師 | すり替えの証言 → **機会** |
| 9 | 警察署へ移動 | きく → 大場 | **鑑定書**入手 → **手段** |
| 10 | 片桐法律事務所へ移動 | きく → 片桐（3回） | 「薬には何も関わっていない」と言う |
| 11 | 片桐法律事務所 | 手帳 → 矛盾をつく → 「その薬は先週、片桐が病院から…」と「源三の薬には何も関わっていない」→ つきつける | 片桐のうそを崩す |
| 12 | どこでも | すいり → 片桐 | エンディングへ |

この手順なら行動22回前後・ミス0回で「名警部」評価になります。

## 6. 会話の全セリフ

### マコト（いつでも）
- その場所に、まだ大事な話（証言カードになる話）を聞いていない人がいれば「○○さんはまだ何か知っていそうですよ」と教えてくれる
- いなければ、進み具合に合わせたヒントを出す。証言がそろうと「すいりで指名しましょう」と言う

### ハル（居間）
1. 今朝7時、合鍵で書斎を開けて発見した
2. 社長は毎晩10時に薬を飲み、書斎に鍵をかけてこもる習慣だった
3. 昨夜、弟の隆がお金の無心に来て言い争っていた
4. 大事な番号はいつも娘にちなんで決めていた（このあとは繰り返し）

- **カプセルを見せる** → 先週、片桐が病院から受け取ってきた薬だと証言 ★重要（病院が解放）
- メモを見せる → 心当たりなし

### 沙織（居間）
1. 昨日、結婚のことで父と喧嘩した
2. 叔父の隆は毎晩、雀荘「東風」にいる → 雀荘が解放
3. 夜10時ごろは自分の部屋にいた（このあとは繰り返し）

- 帳簿を見せる → 父が調べていたのはこれ…？
- メモを見せる → 叔父も黒木だからKだけど…（ミスリード）

### 大場（警察署）
- カプセルを渡す前：死因は毒。ウイスキーとグラスからは何も出なかった
- **カプセルを見せる** → 鑑定開始
- 渡したあとに移動を1回以上してから「きく」 → **鑑定書**入手（中身は猛毒）
- 鑑定書を受け取ったあと：胃からも同じ毒が出た

### 野村（汐見水産）
1. 社長は最近、会社の金の流れを調べていた
2. 資料は自宅の金庫にしまってあると言っていた
3. 資金管理は片桐に任せていた → 事務所が解放（このあとは繰り返し）

- **帳簿を見せる** → 送金先は片桐の個人口座、3年で3000万円以上 ★動機
- メモを見せる → 社長は金曜日に片桐と会う予定だった

### 店主（雀荘）
- 隆は昨夜9時から朝3時まで店にいた → **隆のアリバイ成立**

### 隆（雀荘）
1. 借金を断られたのは事実だが、やっていない
2. 9時からずっとここにいた

- メモを見せる → 「金曜に片桐と話をつける」と兄がこぼしていた

### 薬剤師（汐見病院）
- きく → 11月16日、片桐が代理で薬を受け取りに来た
- **カプセルを見せる** → 本物には刻印がある。これはすり替えられた偽物 ★機会

### 片桐（法律事務所）
1. 古い友人として残念だ
2. 昨夜は9時から自宅にいた（アリバイはあるが、事件には関係ない）
3. 「源三の薬には何も関わっていない」（**うそ**。証言カードになる）

- 帳簿を見せる → 「正式な送金だ」（額に汗）
- カプセルを見せる → 「見たこともない」
- 鑑定書を見せる → 「関係のない話だ」

## 8. 矛盾をつく

手帳の「証言カード」タブで「矛盾をつく」を押し、食い違うカードを2枚選んで「つきつける」。

| 組み合わせ | 結果 |
|---|---|
| 片桐「源三の薬には何も関わっていない」＋ ハル「その薬は先週、片桐が病院からもらってきたもの」 | 正解。片桐が薬を受け取ったことを認める |
| 片桐「源三の薬には何も関わっていない」＋ 薬剤師「11月16日、片桐が代理で社長の薬を受け取った」 | 同じく正解 |
| 正しい組み合わせを、片桐法律事務所以外でつきつける | 「本人に突きつけましょう」と言われる（ミスにならない） |
| それ以外の組み合わせ | ミス1回 |
