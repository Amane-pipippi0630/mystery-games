## 1. 真相（ひとことで）

**長尾秀樹（68歳）を死なせたのは、時計職人の宮下千鶴（71歳）。遺体を動かして死亡時刻をずらしたのは、孫の宮下蒼（19歳）。**

| 項目 | 内容 |
|---|---|
| 事件 | 2027年1月14日（木）17時45分ごろ、宮下時計店の作業場。手帳を奪ってストーブで燃やそうとした長尾ともみ合いになり、千鶴は、点検のためにケースの扉を開けていた店の大時計から真鍮の振り子を外して、長尾の頭を打った。長尾は倒れて死んだ |
| 偽装 | 帰ってきた蒼が、祖母を町会の新年会へ行かせた。そのあいだに、裏の路地に停めてあった長尾の車に遺体を乗せ、暖房を最強にして隅田川沿いまで運び、エンジンをかけたまま立ち去った。遺体が冷えるのを遅らせるためだ |
| 狙い | 死亡推定時刻を「20時半ごろ」にずらす。その時間、千鶴は新年会（30人の証人）にいる |
| ほころび | ①暖房が止まったのは燃料切れの21時45分ごろ（霜のでき方）、②暖房の時間を入れて計算し直すと死亡は17時45分ごろ、③蒼が掛け直した振り子の重りが0.4mm下にずれ、大時計だけが1時間に0.73秒ずつ遅れていた |
| 推理の形 | **倒叙**。犯人は最初から分かっている。プレイヤー（刑事・桐生）は「どうやったか」を3つの検証で崩し、最後に「なぜ蒼は遺体を動かしたのか」を当てる |
| なぜ | 祖母を捕まらせたくなかっただけではない。「ばあちゃんは一生かけて手帳を探してた。せめて最後まで読む時間をあげたかった」 |

## 2. 舞台

東京都墨田区の下町、隅田川の近く。町名は架空の「**時雨町（しぐれちょう）**」。

```
［隅田川］──── 堤防下の道（長尾の車が見つかった場所）
     │ 徒歩15分 ／ 車で5分
［時雨町］
  宮下時計店（1階：店・作業場／2階：住まい）── 裏の路地（長尾が車を停めた）
  ├ 隣：立花豆腐店（おかみが17時35分ごろ、怒鳴り声を聞く）
  ├ 角：コンビニ（店員が17時55分、蒼が店に入るのを見る）
  └ 町会会館（徒歩5分。新年会 18:30〜21:00）
［墨田署］捜査本部　［城東工業大学］白石の研究室（蒼は1年生）　［喫茶「振子」］三島と会う
```

**背景（新しく必要）**：時計店の店内／作業場／2階の居間／裏の路地（夜）／町会会館（新年会）／隅田川沿いの道と車（早朝）／墨田署の会議室／大学の研究室／長尾のマンション／喫茶店　計10枚（`docs/art/` に叩き台を作る）

### 数字の根拠（白石の検証で使う）

| 検証 | 数字 |
|---|---|
| 遺体の冷え方（ゲーム用に単純化） | 店内（約20℃）で1時間に0.4℃、暖房の効いた車内（27℃）で0.3℃、冷えた車内（0〜2℃）で1.0℃下がる |
| 警察の最初の見立て | 8:10に25.3℃。冷えた車内だけで逆算 (37−25.3)÷1.0＝11.7時間 → 20時半ごろ |
| 暖房を入れた計算 | 下がった11.7℃のうち、18:35〜21:45（3時間10分）の暖房の車内で0.95℃、21:45〜8:10（10時間25分）の冷えた車内で10.42℃。残りの0.33℃が店内の分で、0.33÷0.4＝約50分 → 死亡は18:35の50分前＝**17時45分ごろ** |
| 振り子 | 秒振り子（長さ約99cm）の重りが0.4mm下がると、1時間に0.73秒遅れる（白石が一晩かけて測る）。1/15 17:45に17.1秒遅れ → 17.1÷0.73＝約23時間25分前 → **1/14 18時20分ごろ**に振り子が掛け直された |
| 温度の影響 | 真鍮の振り子は1℃で1日0.8秒しか変わらない。千鶴は店を一年中20℃に保っている（時計のため）ので、温度では説明がつかない |
| 燃料 | 残り約3L ÷ 1時間0.95L ＝ 約3時間10分。18:35に走り出したので、止まったのは**21時45分ごろ** |
| 霜 | 車の窓の内側の霜の厚さ（7:45に鑑識が測って0.21mm。白石が同じ車種で再現）→ 0.21mmは止まってから10時間後 → **21時45分ごろ** |

### 第1章 鳶色の手帳（千鶴）
- **流れ**：12月20日、磯村が店を訪ねて手帳を返す（場面）→ 年末から年明け、店の仕事・蒼との暮らし・町内の人たちとの会話の合間に、手帳を少しずつ読む → 1月14日、長尾が来る → もみ合い（場面）
- **遊び**：時計の修理（小さな謎：止まった置き時計の原因を見つける）、手帳を読む（日ごとに数ページ）、町内の人と話す（新年会の誘い、豆腐店）
- **手帳で分かること**：引き揚げ船の約束、志乃への仕送りまで。1959年の冬のページは文字が乱れ、「取り返しのつかないことをした」とだけ読める（何をしたかは書かない）。品川の事件は第6章で三島が語る
- **見せ方**：手帳は日ごとに数ページずつしか読めない。第1章の終わりでも、千鶴は最後まで読み終えていない
- **終わり**：振り子を握ったまま立ちつくす千鶴。「…蒼が、帰ってくる」

### 第2章 夜の隅田川（蒼）
- **流れ**：17時55分に帰宅 → 作業場で祖母と倒れた男を見つける → 祖母を新年会へ行かせる（「ばあちゃんは、まだ手帳を読み終わってないんだ」f22）→ 振り子の血を拭いて掛け直す → 台車で遺体を車へ → 暖房を最強にして隅田川沿いへ → エンジンをかけたまま歩いて帰る → 新年会の片づけを手伝い、祖母と帰る
- **遊び**：手順を選んで進める。物理を学ぶ学生として冷え方を計算する場面（第7章の伏線）
- **終わり**：帰り道、祖母が「蒼、ありがとう」とだけ言う

### 第3章 冷たい車（桐生）
- **流れ**：1/15 朝、隅田川沿いの車で遺体 → 検視「20時半ごろ」・ドライブレコーダー「18:47」 → 長尾の身元とマンション（f01）→ 時計店へ。千鶴の話（f04）→ 町会長（f05）→ 豆腐店（f06）→ m1
- **終わり**：千鶴には20時半のアリバイがある。けれど、言い直した「17時50分に帰った」は本当か

### 第4章 物理学者（桐生）
- **流れ**：大学の研究室へ。白石「車は3時間、ずっと誰かを温めていた」→ 車を一緒に調べる（f07・f08）→ 霜の話（f09の予告）
- **遊び**：白石と車を調べる、研究室の雑談（物理の小ネタ）

### 第5章 時計の街（桐生）
- **流れ**：夕方、白石と時計店へ → 30台の時計、大時計だけ17秒遅れ（f10）→ 千鶴の習慣（f11）・温度（f12）→ 蒼と会う。白石「君、私の授業に出ているね」（f15）→ 蒼の帰宅時刻（f13）→ コンビニ（f14）→ m2

### 第6章 三島陽（桐生）
- **流れ**：三島と喫茶店で会う（f16。第一作の事件、1959年の品川、沖田の約束）→ 磯村に電話（f17）→ 町会長（f18）→ 千鶴が誰の娘で、何を探していたかが分かる

### 第7章 検証（桐生）
- **流れ**：白石の研究室で3つの検証（v1〜v3）→ 蒼の授業のレポート、m3 → 蒼の実験ノート（f21）
- **終わり**：死亡は17時45分ごろ、場所は時計店。遺体を動かしたのは蒼

### 第8章 なぜ（桐生）
- **流れ**：時計店で、千鶴と蒼に向き合う → 「遺体を動かしたのは誰か」を指名（推理）→ 蒼「全部、ぼくがやった」、千鶴は首を振る → 最後の問い「なぜ」（選択式）→ 告白 → 結末
- **結末**：千鶴は過剰防衛として起訴され、執行猶予の判決。蒼は死体遺棄で保護観察。千鶴は手帳の破り取られた最後のページの跡をなでる「ここに、何が書いてあったんでしょうね」
